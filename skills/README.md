This repository contains Dpdl skills (aka. Agent Skills)


## DpdlSkills available:

- [**`dpdllang`**](https://github.com/dpdlhub/dpdlplugins/skills/dpdllang) --> skill for generating dpdl code


## Specification

- The YAML frontmatter (`name`, `description`, `license`) follows the emerging **SKILL.md / Agent Skills** convention so agents can auto-discover when to activate this skill. The `description` field is written to maximize trigger matching (file extensions, keywords, feature names).
- The body is organized as a **reference an agent can scan quickly**: syntax blocks, minimal examples, etc..
