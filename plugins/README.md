This repository contains Dpdl plug-ins for executing within dpdl code


## DpdlPlugins available:

- [**`dpdlshell`**](https://github.com/dpdlhub/dpdlplugins/blob/main/plugins/)


## Specification

All plug-ins in this directory follow the DpdlPlugin specification defined at:

[DpdlPlugins.md](https://github.com/Dpdl-io/DpdlEngine/tree/main/doc/specs/DpdlPlugins.md)


## Plug-in Structure

Each Dpdl plug-in consists of a:
- file in `json` format with the plug-in configuration and parameters
- dedicated folder containing the actual plug-in executable package
