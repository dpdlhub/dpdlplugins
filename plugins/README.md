This repository contains Dpdl plug-ins for executing within dpdl code


## DpdlPlugins available:

- [**`dpdlshell`**](https://github.com/dpdlhub/dpdlplugins/blob/main/plugins/dpdlshell.json)


## Specification

All plug-ins in this directory follow the DpdlPlugin specification defined at:

[DpdlPlugins.md](https://github.com/Dpdl-io/DpdlEngine/blob/main/doc/specs/DpdlPlugins.md)


## Plug-in Structure

Each Dpdl plug-in consists of:
- a `json` file with the plug-in configuration and parameters
- a dedicated folder containing the plug-in package
